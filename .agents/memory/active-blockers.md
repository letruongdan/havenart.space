## Blocker Entry Schema

When registering a blocker, use the following template:

```markdown
### [BLOCKER-XXX] Title of Blocker
- **Task ID:** e.g. T4
- **Blocked Agent:** e.g. A4 (Journal)
- **Blocking Agent / Factor:** e.g. A2 (Design Tokens not finalized)
- **Date Logged:** YYYY-MM-DD
- **Severity:** Blocker | High | Medium
- **Description:** Clear explanation of what is preventing progress.
- **Action Required:** Concrete action required to unblock.
- **Owner / Resolver:** Responsible party assigned to resolve.
- **Resolution / ADR:** Link to ADR, PR, or contract resolving the blocker once cleared.
```
